## 裸金属解决的是哪类问题，哪些人该绕开

物理机带来的好处有三个，都是云主机给不了的。

**性能上限不同。** 云主机给到 8 核 16G 已经算高配，物理机常见的是 24 核 48 线程、64G 内存起步，往上还能到 48 核 96 线程加 128G。硬件也能按需加内存、加硬盘、加带宽、加显卡，云主机只能在预设套餐里挑。

**没有邻居。** 云主机上跑得忽快忽慢，很多时候来自同宿主机上别人的占用。物理机不存在这个问题，I/O 带宽和 CPU 都是你自己的。

**物理隔离满足合规要求。** 医疗、金融、政府领域的数据隐私法规要求计算资源完全隔离，物理机通过独占硬件规避了多租户环境下的侧信道攻击，也能配合 TPM 2.0 这类硬件级加密。

## 裸金属租赁和云上裸金属，差的不是性能

这两个词经常被混着用，实际差别在交付和管理方式上，不在硬件本身。资源层几乎没有区别，两边都是独占物理机，性能没有本质差异。

| 维度 | 传统裸金属租赁 | 云上裸金属 |
| --- | --- | --- |
| 资源层 | 独占物理机 | 独占物理机，性能无本质差异 |
| 交付方式 | 人工或工单交付，周期较长 | 控制台或 API 交付，分钟级上线 |
| 弹性能力 | 扩容依赖采购和上架 | 按需创建、按需释放 |
| 网络与生态 | 以机房网络为主，架构要自建 | 可直接接 VPC、负载均衡、云存储 |
| 运维模式 | 偏人工 | 自动化运维，生命周期可管理 |
| 价格构成 | 硬件 + 机位 + 带宽 | 硬件 + 调度与云化能力 |

云上裸金属贵出来的部分，花在了控制台、API、调度系统的研发和维护上，也花在弹性能力、网络虚拟化、云生态接入和自动化运维体系上。多付的钱买的是调度能力和云化能力，不是算力本身。

换个说法更容易理解：传统租赁像租一套房子，基础设施齐全，但水电网都得自己打理；云上裸金属像酒店式公寓，带统一的管理和服务体系。

谁适合哪一种，看业务形态。长期稳定负载、成本敏感、有运维团队、要做私有化部署，传统租赁更合适；AI 训练和 GPU 集群、大数据平台、需要弹性扩缩容的业务、混合云架构，云上裸金属更合适。雨云这类产品落在前者，胜在便宜、机型明码标价、远程管理给得比较全。

## 怎么识别“伪云裸金属”

不少“算力租赁”方案会把 GPU 服务器、IB 高速网络、远程可用当作卖点，看着像云服务，用起来还是传统托管。判断标准有三条，全部命中就是传统租赁：

- [ ] 没有云控制台，开通、重装、退还都要走工单或找客服
- [ ] 没有 API 能力，或者只有查询接口，创建、重装、退还都得人工
- [ ] 不支持弹性调度，扩容要等采购和上架，释放要等流程

这三条不是挑刺，它们直接决定你半夜服务器起不来的时候能不能自己处理。一个能自助硬重启、自助重装系统的入口，价值比多 8 个核高。

成熟云厂商的裸金属产品，能力清单通常是这样的：创建、开机、关机、重启、重装、退还这些生命周期操作；绑定和解绑弹性公网 IP、调整带宽；带外账号查询与密码重置；IP 申请与回收；置放群组，还包括分散置放群组；心跳网络组；安全组与自定义镜像。腾讯云 FinCloud 的 BMS 文档目录就是这套结构，API 版本停在 2018-08-13，说明这套接口形态已经稳定了很多年。拿这张清单去问销售，能答上来几项，产品成熟度就有数了。

## 选型参数与验收清单

配置怎么定，按业务类型倒推最快。

**CPU**：通用计算看 Intel Xeon Scalable 系列，内存密集型任务看 AMD EPYC。买二手平台机型时要接受单核性能的折让，E5 v4 的多核性价比高，单核打不过新平台。

**内存**：优先 ECC，容量在预估峰值上再留 20%–30% 余量。内存不够导致的 OOM 比 CPU 跑满难排查得多。

**存储**：NVMe SSD 适合低延迟场景，全闪存阵列适合高吞吐场景。需要多盘的要先确认阵列卡方案，软件阵列会占掉一部分 CPU。

**网络**：25G 以太网可以当基准，HPC 场景再考虑 InfiniBand。网卡直通（SR-IOV）和 DPDK 硬件卸载能明显降低网络开销。

带外管理是物理机和“租个机柜放服务器”的分水岭，靠 IPMI 或 Redfish 接口实现，能做的事情包括：

- 远程电源控制，开机、关机、重启
- 硬件健康监控，温度、电压、风扇转速
- 虚拟介质挂载，用 ISO 远程装系统
- 固件更新与 BIOS 配置

雨云用的是 IPMI 加 NanoKVM 的方案，支持硬关机开机、重装系统，部分机型还能进 BIOS 改设置。服务器彻底死机时能不能自己硬重启，决定了你要不要半夜打电话找人。

向供应商确认这四件事，基本能筛掉不靠谱的：

1. **硬件兼容性**：是否支持主流 Linux、Windows Server，以及 VMware、KVM 这类虚拟化平台
2. **管理能力**：有没有完整的带外管理 API 和自动化工具链，不只是给个网页控制台
3. **SLA**：硬件故障更换时间通常要求 ≤4 小时，网络可用性 ≥99.99%
4. **成本模型**：按需付费和预留实例的价差有多大，续费价跟首单价是否一致

## 机房位置决定价格，也决定合规

区域、场景、合规这三件事在物理机选型里是绑在一起的，不是分开考虑的。

国内核心城市（北京、上海、广州）适合时延敏感业务，比如金融交易、实时推理，机房一般会拿等保 2.0 三级认证。西部数据中心（贵阳、贵安新区、庆阳、中卫）适合大规模计算和存储，能享受西部电价优惠和政策支持，多数属于国家算力枢纽节点。东南亚节点（新加坡、雅加达）服务出海企业，要过 GDPR 合规认证。

西部电价优惠对长期跑满负载的业务是实打实的成本差异，代价是到东部用户的网络延迟。做实时推理的别为了省电费把机器放西部，做离线训练的没必要挤在核心城市。
